매일 우리는 웹 브라우저를 켜고 수많은 작업을 처리합니다. 온라인 쇼핑몰에서 필요한 물건을 찾고, 레스토랑을 예약하고, 채용 플랫폼에서 정보를 탐색하고, 소셜 미디어에서 지인과 소통하죠. 이 모든 과정은 반복적이지만, 놀랍게도 여전히 상당 부분을 수동으로 처리하고 있습니다. 하지만 만약 인공지능이 여러분 대신 이 모든 웹 기반 작업을 알아서 척척 해낼 수 있다면 어떨까요? 그저 "이번 주말 저녁에 친구와 갈 만한 아시아 음식점을 오픈테이블에서 찾아 예약해 줘"라고 말하기만 하면, AI가 웹사이트를 뒤져 예약까지 완료해 준다면? 꿈같은 이야기처럼 들리겠지만, 바로 이러한 미래를 현실로 만들겠다고 나선 스타트업이 있습니다. 최근 7억 달러라는 엄청난 규모의 시리즈 A 투자를 유치한 Hark가 선보인 'Hark Handoff' 에이전트가 바로 그 주인공입니다.

## 웹 브라우저, AI 에이전트의 새로운 전장인가?

Hark Handoff는 단순히 정해진 규칙에 따라 작동하는 자동화 도구가 아닙니다. 이 에이전트의 핵심은 웹 브라우저를 마치 사람이 사용하는 것처럼 효율적으로 다룰 수 있다는 점입니다. 특히 주목할 만한 점은 Target, Walmart, OpenTable, LinkedIn과 같이 **공식 API가 없는 웹사이트도 손쉽게 탐색할 수 있다**는 Hark의 주장입니다. 이는 기존의 소프트웨어 로봇 프로세스 자동화(RPA)나 API 기반 통합으로는 접근하기 어려웠던 영역을 AI 에이전트가 직접적으로 공략하겠다는 의미입니다.

솔직히 말해서, 이 지점이 많은 사용자에게 가장 큰 매력으로 다가올 것입니다. 개발자 입장에서 보면 API가 없는 웹사이트는 데이터를 가져오거나 특정 기능을 자동화하기가 까다로운 '블랙박스'와 같습니다. 하지만 Hark는 Handoff 에이전트가 **웹사이트 구조와 시각적 데이터를 분석하여** 어디를 클릭해야 할지, 어떤 정보를 입력해야 할지 스스로 판단한다고 설명합니다. 마치 인간이 웹페이지를 눈으로 보고 이해한 후 행동하는 방식과 유사하다고 볼 수 있습니다. 이는 기존 LLM들이 단순히 텍스트를 이해하고 생성하는 수준을 넘어, 시각적 맥락을 파악하고 실제 '행동'을 예측하는 멀티모달 능력의 중요성을 다시 한번 강조하는 대목입니다.

실제로 CEO인 브렛 애드콕(Brett Adcock)은 시연 영상에서 사용자가 지정한 꽃으로 꽃다발을 만들고, "플로리스트가 고른 것 중 일부"와 같은 모호한 용어까지 수용하여 주문을 처리하는 모습을 보여주었습니다. 다만 아쉬운 점은 영상이 전체 프로세스의 일부만을 보여주었기 때문에, 실제 환경에서의 효과를 명확히 가늠하기는 어렵다는 것입니다. 이 부분에서 필자는 조금 더 비판적인 시각으로 접근할 필요가 있다고 생각합니다. 웹 인터페이스는 끊임없이 변합니다. 작은 UI 변경이나 새로운 광고 배너 하나에도 시각적 데이터를 기반으로 한 에이전트의 오작동 가능성이 존재할 수 있습니다. Hark가 이러한 동적인 웹 환경 변화에 얼마나 유연하게 대응할 수 있을지가 Handoff의 성공을 가르는 중요한 시험대가 될 것입니다.

## Hark Handoff, 무엇이 다르고 무엇이 더 싼가?

Hark Handoff가 단순히 웹 자동화 도구에 머무르지 않고, 빠르게 성장하는 AI 에이전트 시장에서 독보적인 위치를 차지하려는 노력이 엿보이는 지점은 바로 그들의 기술적 접근 방식과 비용 효율성 주장입니다.

**기술적 차별점: '다음 토큰'이 아닌 '다음 행동' 예측**

Hark는 이번 Handoff 출시를 위해 **사후 학습된 모델(post-trained model)**을 사용하고 있으며, 올해 말에는 사전 학습(pre-train) 모델로 전환할 계획이라고 밝혔습니다. 이러한 접근 방식은 데이터 파이프라인, 훈련 인프라, 그리고 기술을 더 빠르게 개선할 수 있게 해준다고 설명합니다.

여기서 가장 중요한 비교 우위는 Hark의 모델이 **대규모 언어 모델(LLM)처럼 '다음 토큰'을 예측하는 대신, '다음 행동'을 예측할 수 있다**고 주장하는 점입니다. 이 차이는 매우 중요합니다.
*   **다음 토큰 예측 (LLM):** GPT나 Opus 같은 LLM은 주어진 텍스트의 맥락을 바탕으로 다음에 올 가장 확률 높은 단어(토큰)를 예측하여 문장을 생성합니다. 이는 주로 언어 이해 및 생성에 특화되어 있습니다.
*   **다음 행동 예측 (Hark Handoff):** Hark의 모델은 사용자의 목표 달성을 위해 웹 페이지 내에서 이루어져야 할 구체적인 상호작용(특정 버튼 클릭, 특정 입력 필드에 텍스트 입력 등)을 예측합니다. 즉, 텍스트 처리에서 한 단계 나아가 시각적 요소와 맥락을 종합하여 '행동'을 결정하는 데 초점을 맞춥니다.

![Hark previews its browser use agent for completing tasks](https://techcrunch.com/wp-content/uploads/2026/08/Screenshot-2026-08-05-at-8.10.59-PM.jpg?resize=1200,596)

이러한 '행동 예측' 모델은 웹 환경에서의 작업 자동화에 훨씬 더 직접적이고 효율적일 수 있습니다. 마치 인간이 웹사이트를 볼 때 "여기서는 이 버튼을 눌러야 다음 단계로 넘어갈 수 있겠군" 하고 생각하는 것과 비슷합니다. 이는 복잡한 다단계 작업을 처리하는 데 있어 LLM만을 사용하는 것보다 더 적합한 접근 방식일 수 있다는 것이죠.

**경쟁력: 속도와 비용 효율성**

현재 컴퓨터 사용 에이전트 분야는 Google, OpenAI, Anthropic과 같은 거대 기술 기업들뿐만 아니라 Browser Use, Polar, Strawberry, Aside와 같은 VC 투자를 받은 스타트업들도 브라우저 기반 작업 자동화에 뛰어들며 치열한 경쟁을 벌이고 있습니다. 이 시장은 잠재력이 무궁무진하지만, 동시에 높은 기술력과 효율성을 요구합니다.

Hark는 이러한 경쟁 환경 속에서 Handoff 에이전트가 **경쟁사보다 더 빠르고, GPT 5.5나 Opus 4.8과 같은 다른 모델보다 훨씬 저렴하다**고 대담하게 주장합니다. 사실 이건 매우 중요한 포인트입니다. AI 기술의 발전과 함께 비용은 항상 중요한 고려 사항이었으니까요. 만약 Hark의 주장이 사실이라면, Handoff는 기업 및 개인 사용자에게 AI 에이전트 솔루션의 접근성을 크게 높일 수 있을 것입니다.

개인적으로는 이 비용 절감 주장에 큰 기대와 함께 몇 가지 질문이 떠오릅니다. '훨씬 저렴하다'는 것이 어떤 기준으로 측정된 것일까요? 단순히 모델 추론 비용만을 의미하는 것인지, 아니면 전체 솔루션의 구축 및 운영 비용까지 포함하는 것인지 명확한 검증이 필요합니다. 또한, 속도가 빠르고 저렴하다는 것이 작업의 정확성과 신뢰성을 희생하지 않으면서 달성된 것인지도 중요합니다. AI 에이전트가 처리하는 작업은 때때로 금전적인 손실이나 중요한 정보 처리와 직결될 수 있기 때문입니다. 그럼에도 불구하고, 만약 Hark가 이 두 마리 토끼를 모두 잡는 데 성공한다면, 이는 브라우저 기반 자동화 시장에 엄청난 파급 효과를 가져올 것입니다.

Hark는 현재 플랫폼 대기자 명단을 받고 있으며, 올 여름 말까지 출시할 계획이라고 합니다. 사용자들은 과연 그들의 주장이 실제 성능으로 이어질지 곧 직접 확인할 수 있게 될 것입니다.

## 에이전트 시대의 서막, 그리고 남겨진 질문들

Hark Handoff와 같은 브라우저 사용 에이전트의 등장은 우리가 인터넷과 상호작용하는 방식에 혁명적인 변화를 가져올 잠재력을 가지고 있습니다. 단순 반복 작업에서 벗어나 더 생산적이고 창의적인 활동에 집중할 수 있게 해주는 것이죠. 더 이상 복잡한 양식 작성을 위해 마우스를 수없이 클릭하고 키보드를 두드릴 필요 없이, AI가 모든 것을 알아서 처리해 주는 미래를 상상해 보세요. 이는 개인 사용자뿐만 아니라 웹 기반 업무 프로세스가 많은 기업들에게도 엄청난 효율성 증대를 가져다줄 수 있습니다.

하지만 동시에 이러한 기술의 발전은 여러 질문을 남깁니다. Hark Handoff가 주장하는 속도와 비용 효율성, 그리고 API 없이도 웹사이트를 능숙하게 다루는 능력은 실제 상용 환경에서 얼마나 안정적으로 발휘될까요? 동적으로 변하는 웹 환경과 예상치 못한 오류에 얼마나 효과적으로 대처할 수 있을까요? 또한, 이러한 에이전트 기술이 발달할수록 웹 개발자들은 'API를 제공할 필요가 없는' 상황에 직면하게 될까요, 아니면 에이전트의 접근을 차단하는 새로운 방어 기법을 모색하게 될까요?

Hark Handoff는 웹 자동화의 새로운 시대를 예고하며 흥미로운 기술적 도전과 혁신을 제시하고 있습니다. 이제 남은 것은 그들의 야심 찬 주장이 실제 사용자들의 기대치를 얼마나 충족시킬 수 있을지 지켜보는 것입니다. 올 여름, Handoff가 우리에게 어떤 새로운 경험을 선사할지 벌써부터 기대가 됩니다.
